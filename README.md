# 🎵 Slide de Implementação de Música em Jogos Usando o Godot

Bem-vindo ao repositório desta apresentação! Este projeto contém os slides e materiais de apoio sobre como integrar e manipular trilhas sonoras e efeitos de áudio na engine Godot.

## 🎯 Sobre o Projeto

O objetivo desta apresentação é mostrar o passo a passo da implementação de áudio em jogos, desde a importação de arquivos até o controle de música dinâmica via código (GDScript). É um material voltado para desenvolvedores e entusiastas de game dev que desejam melhorar a experiência sonora de seus jogos.

## 📝 Tópicos Abordados

* Importação de arquivos de áudio (WAV, OGG).
* Configuração do nó `AudioStreamPlayer`.
* Criação de loops de música perfeitos.
* Controle de volume e efeitos via Audio Buses.
* Transições suaves (Fade in / Fade out) usando GDScript e Tween.
